# mistralelectrique.com redirect

Sends every visit on mistralelectrique.com (and www) to the same path on https://mistralelectric.com.
`index.html` handles the root, `404.html` catches every other path; both redirect with the path kept.
Served by GitHub Pages from `main`, custom domain `mistralelectrique.com`. The site itself lives in
TheMeatMusic/mistral-website. Nothing here should ever need to change.
